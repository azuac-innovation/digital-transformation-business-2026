# digital-transformation-business-2026


# I. Müqəddimə
Bu tədris planı ali təhsilin maqistr pilləsində əyani təhsil alan tələbələrə “Biznesin idarə edilməsində rəqəmsal transfarmasiya” fənninin tədrisi üçün işlənib hazırlanmışdır. Sillabus fənnin fənn proqramı əsasında tərtib edilmişdir.
Fənn auditoriyalarda mühazirələrin  oxunması, praktik  məşğələlərin  aparılması və tələbələrə fənni tədris edən müəllim tərəfindən verilən mövzular üzrə sərbəst işlərin yerinə yetirilməsi yolu ilə öyrənilir. 
“Biznesin idarə edilməsində rəqəmsal transformasiya” fənni tələbələrə ənənəvi biznes strukturlarının müasir texnologiyalar vasitəsilə necə yenidən formalaşdırılmasını və rəqəmsal dövrün tələblərinə uyğunlaşdırılmasını öyrədir. Kurs nəzəri biliklərlə yanaşı, real nümunələrin və praktiki alətlərin tətbiqinə əsaslanır.

# II. Fənninin öyrənilməsinin məqsədi
Fənnin məqsədi Azərbaycanın müxtəlif dövlət və özəl sektorlarında əmək fəaliyyətinə başlayacaq tələbələrə rəqəmsal iqtisadiyyatın tələblərinə uyğun peşə kompetensiyaları aşılamaq və onlara biznesin rəqəmsal transformasiyası üzrə həm nəzəri, həm də praktik biliklər təqdim etməkdir. Dünya təcrübəsi göstərir ki, XXI əsrdə “rəqəmsal çeviklik” və “texnoloji savadlılıq” fəaliyyət sahəsindən asılı olmayaraq bütün menecerlər üçün mütləq kompetensiyalar toplusuna daxildir. “Rəqəmsal yanaşma” və “məlumatlara əsaslanan təfəkkür” istənilən biznes strukturunda səmərəliliyi artırmağa və qlobal rəqabətə davam gətirməyə imkan yaradır. Bunu nəzərə alaraq, bu fənn ali təhsil müəssisəsinin müasir bazarın çağırışlarına cavab verən “yeni nəsil mütəxəssislərini” yetişdirməsində həlledici rol oynayacaqdır. Fənnin tədris materialları və metodologiyası beynəlxalq standartlara, o cümlədən müasir rəqəmsal idarəetmə prinsiplərinə tam uyğundur və tələbələrin gələcəkdə rəqəmsal transformasiya üzrə beynəlxalq sertifikatlar alması üçün baza rolunu oynayır.


# Fənn üzrə bilik və bacarıqlara olan tələblər.
Fənnin öyrənilməsi nəticəsində tələbələr aşağıdakıları bilməlidirlər:
●	Rəqəmsal strategiyanın əsaslarını: Biznes modellərinin transformasiyası, rəqəmsal iqtisadiyyatın prinsipləri və strateji planlaşdırma alətlərini (SWOT, PEST, KPI);
●	Texnoloji ekosistemi: Süni intellekt (AI), Blokçeyn, Böyük verilənlər (Big Data) və Bulud texnologiyalarının biznesə təsir mexanizmlərini;
●	İdarəetmə sistemlərini: ERP və CRM sistemlərinin (SAP, Salesforce) müəssisənin resurslarının idarə olunmasında rolunu;
●	Metodoloji çərçivələri: Çevik layihə idarəetmə metodologiyalarının (Agile, Scrum) və Sənaye 4.0 konsepsiyasının mahiyyətini;
●	Hüquqi və etik normaları: Məlumatların qorunması (GDPR), kiber-təhlükəsizlik və rəqəmsal etika qaydalarını.

# Fənni öyrənən tələbələr aşağdakıları bacarmalıdırlar:
●	Analiz və diaqnostika: Ənənəvi biznes modelindəki boşluqları müəyyən etməyi və rəqəmsal keçid üçün yol xəritəsi (Roadmap) hazırlamağı;
●	Praktiki tətbiq: Jira, Zoho CRM və ya digər idarəetmə platformaları vasitəsilə biznes proseslərini rəqəmsal olaraq idarə etməyi;
●	Məhsulun hazırlanması: Startap yanaşması ilə MVP (Minimum Həyat qabiliyyətli Məhsul) konsepsiyasını qurmağı və sınaqdan keçirməyi;
●	Qərar qəbul etmə: Məlumatlara əsaslanan (Data-driven) yanaşma ilə biznes problemlərini həll etməyi və proqnozlar verməyi;
●	İstifadəçi təcrübəsinin dizaynı: Müştəri məmnuniyyətini artırmaq üçün rəqəmsal istifadəçi təcrübəsini (UX/UI) qiymətləndirməyi və optimallaşdırmağı.
